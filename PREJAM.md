# Pre-jam declaration

Team entry for the 2026 Epic AI MegaJam. The jam window opens on 2026-11-12 at 05:00 UTC (00:00 ET).
This file lists everything that existed in the repository before that moment. Every commit made before the start
carries the prefix "pre-jam:".

## What the repository holds before the start

No gameplay code, no levels, no art, no sound. Only tooling, agent configuration and an empty project skeleton.

## Tools outside the repository

- **Unreal Engine 5.8** with the built-in plugins ModelContextProtocol, MCPClientToolset, AllToolsets,
  LiveCodingToolset.
- **Claude Code** (Anthropic) as the coding agent.
- **MCP stdio bridge** `unreal-mcp-bridge` (https://github.com/exetorius/unreal-mcp-bridge, MIT licence): a
  third-party open-source relay that keeps Claude Code connected to the editor's MCP server across restarts.
- **Global Claude Code skills and hooks** of the author (`~/.claude/skills`: grilling, tdd, to-tickets and others;
  `~/.claude/hooks`: bash-guard, comms-guard, workflow-guard). Process helpers, no game content.
- **rtk**: a CLI proxy that shortens command output for the agent.
- **clang-format 22.1.8, lizard 1.24.3**: code checks.

Tools added during the jam (generators of art, sound, music, video) are listed in the dev log as they come in.

## Discussed before the start

The theme was announced on 11 November. From then until the start the team prepared in one planning session with
Claude Code: the rules brief, the team interview, this tooling setup and the concept discussion that ended with
`JAM_PLAN.md`. That session is planning, not development, so its log is not part of `_AgentLogs/`; the author keeps
it locally. The development log starts with the first jam session, opened by `JAM_START_PROMPT.md`.

Nothing from the discussion was implemented before the jam window: no gameplay code, no levels, no art, no sound.
