## Claude (2026-11-14 19:28 UTC)

Use the top-level `autoCompactWindow` key in settings.json: `"autoCompactWindow": 350000`. It is the official key. The `CLAUDE_CODE_AUTO_COMPACT_WINDOW` variable also exists and overrides it.

- **Key and location:** top-level key in `~/.claude/settings.json` or a project settings file. Also `/autocompact 350k` in-session, which saves per model under `modelSettings`. Source: https://code.claude.com/docs/en/settings-reference.md and https://code.claude.com/docs/en/model-config.md
- **Units and values:** tokens, 100000 to 1000000, capped at the model's context window. The `k`/`M` suffixes are documented for the command, flag, and env var (v2.1.304+), not explicitly for the JSON key. Source: model-config.md
- **Env var:** `CLAUDE_CODE_AUTO_COMPACT_WINDOW` takes precedence over the key. Source: https://code.claude.com/docs/en/env-vars.md
- **`CLAUDE_AUTOCOMPACT_PCT_OVERRIDE`:** a 1-100 percentage that can only lower the threshold. Source: env-vars.md
- **1M only:** not required. A 350k value is capped at 200k on a 200K-window model.
- **Restart:** not found in docs for the key. Shell-exported env vars need a relaunch.
